07 / Manutenção

Como manter esta página

  • Mudou um valor em tokens.css (uma cor, um tamanho)? Nada a fazer: esta página lê o arquivo.
  • Criou um token novo? Adicione uma amostra na seção Tokens (os valores aparecem sozinhos pelo atributo data-token).
  • Criou ou mudou um componente em base.css? Atualize o exemplo em Componentes copiando o HTML do template indicado no rótulo.
  • Mudou um par de cores? Inclua a combinação na tabela de contraste.
